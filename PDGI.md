# How RFPartnerMap follows PDGI

An interactive India map of Rainmatter's ~114 partners, artefacts and place-thesis profiles. Built on **People's Digital Goods & Infrastructure (PDGI)** principles — people before digital, rights-centric, commons-oriented, transparent ([pdgi.org](https://pdgi.org/)).

This is a public scorecard of how those principles are implemented here, with honest notes on where it falls short. It was generated from a repository audit (2026-07); update it as the code changes.

Status key: ✅ implemented · 🟡 partial · ⛳ gap · — not applicable.

## Scorecard

### People before digital — ✅
Serves the ecosystem / place thesis, not engagement metrics.

### Transparency and accountability — ✅
Per-partner source trails and an artefact ledger with citations.

### Decentralisation and no lock-in — ✅
Vanilla single-file app; Excel / payload export; no backend.

### Free software and the digital commons — 🟡
Public with a PR flow, but CC BY-NC (non-commercial) — and the data is © Rainmatter Foundation, so relaxing the licence is a Foundation decision.

### Privacy — ✅
Zero analytics or trackers.

### Platform cooperativism — 🟡
Correction path added (CONTRIBUTING + issue template); fork+PR documented; no in-app submit.

### Humans in the loop (AI does not cut people out) — —
No AI / LLM surface.

### A non-digital alternative — ⛳
Web-only; no printable / offline partner sheet.

### Grassroots and reaching the divide-affected — ⛳
English-only. Direction: vernacular partner summaries.

### Algorithmic fairness — —
A static visualisation; no ranking algorithm.

**Overall:** 4✅ 2🟡 2⛳
